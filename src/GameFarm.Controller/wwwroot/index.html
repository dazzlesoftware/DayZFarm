Host Plugins

Admin-configured commands that run directly on this Controller's host. Add one by placing a JSON file under Config\Plugins\ — see docs/PLUGINS.md. Nothing here accepts free-form commands; only a plugin already defined on disk can be run.

Agent Package

Upload a new Agent build (a zip of dotnet publish src/GameFarm.Agent's output) here, then push it to clients with each row's Update Agent button or the toolbar's Update Agent Selected/All — see docs/AGENT-UPDATES.md. Distinct from Update, which updates the DayZ game install via Steam, not the Agent itself.

VMware Master Password

Only needed if the master VMX has VMware encryption enabled — vmrun refuses to do anything to an encrypted VM (including linked-clone Create Client) without this. Stored the same way as every other secret here (DPAPI, never returned once set). Irrelevant if you're on the Hyper-V backend, or a VMware master with no encryption. See docs/VMWARE-SETUP.md.
